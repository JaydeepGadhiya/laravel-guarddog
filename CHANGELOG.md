## [1.1.0] - 2025-05-19

### Added
- Initial release of Laravel GuardDog
- SQL injection scanner (raw DB queries)
- CSRF protection scanner
- Route authentication scanner
- File upload validation scanner
- Environment configuration scanner
- Security score system (0–100)
- HTML report generation with circular progress bar
- Console output with severity badges
- Configurable scan paths via config/guarddog.php
- Support for Laravel 8 through 13
